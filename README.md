# VoxelRBX

Create polished, detailed 3D models with a Roblox-inspired voxel style.

VoxelRBX guides AI to build models with layered blocky geometry, balanced proportions, subtle studs, and cohesive colors. The goal is models that feel detailed and distinctive while staying readable and game-ready.

## Style guide

- Use varied blocks and layered shapes to create depth.
- Keep the silhouette clear and proportions balanced.
- Use studs as subtle surface details.
- Choose a cohesive palette with enough contrast to separate features.
- Allow slopes, wedges, and cylinders when they improve the design.
- Keep the overall look blocky and Roblox-inspired.

## Examples

Use VoxelRBX when creating Roblox-style:

- Pets and creatures
- Weapons and armor
- Props and collectibles
- Vehicles and decorative assets

## Install

Download [`voxelrbx.skill`](./voxelrbx.skill) and import it through your AI platform’s Skills settings.
